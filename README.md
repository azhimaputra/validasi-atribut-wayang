# Validasi penamaan atribut wayang

Formulir satu halaman untuk narasumber (dalang) menamai atribut pada 16 foto
wayang gaya Surakarta dari koleksi Ki Srihadi. Isian bebas tanpa pilihan
jawaban, supaya penamaan narasumber tidak terarahkan oleh istilah peneliti.

Jawaban tidak dikirim ke server mana pun: halaman ini menyimpan isian di
peramban narasumber, lalu tombol kirim menyusunnya menjadi satu pesan WhatsApp.

Bagian dari riset klasifikasi atribut anatomi wayang kulit, Universitas Dian
Nuswantoro, pembimbing Khafiizh Hastuti.
